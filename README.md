# ✊✋✌️ Rock Paper Scissors

A simple browser-based Rock Paper Scissors game built using vanilla JavaScript. The game randomly generates the computer’s choice, compares it with the user’s selection, displays the result, and keeps track of wins, losses, and ties.

This project was created to practice JavaScript fundamentals and DOM manipulation.

---

## 🎮 Features
- Play Rock, Paper, or Scissors against the computer
- Random computer choice on every round
- Displays game result (Win / Lose / Tie)
- Live score tracking
- Reset score functionality

---

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript (Vanilla JS)
